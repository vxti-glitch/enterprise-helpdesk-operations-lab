# Screenshot evidence

`application/` contains genuine screenshots of the Northstar Help Desk Operations Console displaying simulated portfolio data. They prove that this repository's static application was built; they do **not** prove production ServiceNow, Active Directory, Microsoft 365, or employer experience.

Do not place raw lab captures here. Keep raw personal-lab evidence in `evidence/private/`, redact it, confirm every identifier is fictional, then add only approved `LAB-EXECUTED` evidence in `lab-executed/` with a matching manifest in `evidence/manifests/`. Recommended captures are listed in `docs/EVIDENCE_GUIDE.md`.
