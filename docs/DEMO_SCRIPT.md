# 90-second portfolio demonstration script

> Keep the wording honest: this is a fictional portfolio lab, not production support history.

1. **Open the overview (15 seconds).**
   “This is Northstar, a static console I built around fictional help-desk records. The label stays visible so nobody mistakes the data for production activity. The metrics are derived from the event history, including three deliberately retained difficult cases.”

2. **Open INC012 (20 seconds).**
   “For this networking case, I can explain the support flow from the user report through DNS isolation, a bounded finding, the resolution, validation, and the user-facing closure message. The timeline makes it easy to show what happened and when.”

3. **Open INC009 (20 seconds).**
   “This security case is about scope discipline. Tier 1 gathers safe facts and gives the user immediate guidance, but does not pretend to perform a security investigation. The handoff records the resolver group and the required context.”

4. **Open an asset (15 seconds).**
   “The asset view connects a fictional device to its assigned user and related cases. I intentionally did not add fake live controls like wipe or disable actions.”

5. **Close with quality and next steps (20 seconds).**
   “The data is validated before reports and the console are generated. The optional AD scripts are locked to a sentinel-marked synthetic lab OU. My next step is personally executing a few cases in an isolated lab and adding redacted LAB-EXECUTED evidence.”
