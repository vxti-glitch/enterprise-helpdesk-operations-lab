# Simulation boundaries

## What this repository proves

It proves that the author can organize an IT support lab, apply a consistent ticket schema, document troubleshooting logic, recognize authorization boundaries, write safe automation, calculate operational metrics, and explain a Tier 1 workflow.

## What this repository does not prove

It does not prove employment, production access, live-user support, ownership of a ServiceNow instance, administration of a Microsoft 365 tenant, achievement of a real SLA, or completion of the documented actions on company systems.

## Evidence labels

| Label | Meaning |
|---|---|
| `SIMULATED` | Written scenario or record created for the portfolio; no system execution implied |
| `SYNTHETIC` | Invented identity, asset, timestamp, identifier, or output value |
| `SAMPLE OUTPUT` | Representative sanitized text showing the expected evidence format |
| `LAB-EXECUTED` | May be used only after the author personally executes the step in an authorized lab and captures evidence |

All committed tickets, CSV records, and sample evidence are `SIMULATED` or `SYNTHETIC`.

## Technology-specific boundaries

- **ServiceNow:** Fields are modeled after common incident-management concepts. The generated CSV is a mapping aid, not a platform export. Screenshots are not included because none were captured from a real learning instance.
- **Active Directory:** Scripts are functional lab helpers, but committed evidence is illustrative. The scripts require a domain the operator builds separately.
- **Microsoft 365, Entra ID, and Intune:** Workflow steps show decisions, approvals, and validation paths. They are simulated unless the author separately has legitimate tenant access.
- **Networking and VPN:** Cases document client-side reasoning. Private VPN concentrators and internal services are not included.
- **Security:** Tier 1 verifies the report, preserves useful facts, avoids invasive investigation, and escalates to the fictional Security group.

## Interview rule

A defensible description is: "I built a simulated enterprise service-desk lab and can walk through the data model, scripts, ticket reasoning, and metrics. The cloud and ServiceNow records are simulations; the scripts can be run in an isolated lab."

An indefensible description is: "I supported Northstar Solutions employees in production."
