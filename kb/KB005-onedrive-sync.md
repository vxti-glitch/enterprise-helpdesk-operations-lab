# KB005 - Resolve OneDrive sync issues

**Audience:** Tier 1 service desk<br>
**Portfolio status:** SIMULATED procedure

## Triage checklist

1. Check known service status through the approved source.
2. Confirm the signed-in work account and expected library.
3. Check available local and cloud storage.
4. Inspect the exact sync error and affected file count.
5. Check filename rules, path length, open/locked files, and permissions.
6. Compare web access with local-client behavior.

Do not delete local content or reset the sync client until you have verified authoritative copies and organizational backup/retention policy.

## Validate

- Client reports Up to date.
- A controlled test file appears in the expected web location.
- The affected existing file can be opened.
- No duplicate library or unexpected account is connected.

## Escalate when

Service health is degraded; permissions require owner approval; many users are affected; retention/legal hold applies; data loss is suspected; or reset/relink would risk unsynchronized content.
