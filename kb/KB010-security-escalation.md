# KB010 - Security incident escalation checklist

**Audience:** Tier 1 service desk<br>
**Portfolio status:** SIMULATED procedure

## Immediate Tier 1 actions

1. Verify the reporter through the approved channel.
2. Tell the user not to open links, attachments, or unfamiliar MFA prompts.
3. Record when the event occurred, what the user observed, and whether they interacted.
4. Preserve the message or alert through the approved method.
5. Perform only pre-authorized containment steps such as session revocation or password reset when policy directs.
6. Escalate to Security with a specific request and update expectation.

## Do not

- Open a suspicious link to "test" it.
- Forward a suspicious attachment outside the approved reporting path.
- Search unrelated mailbox content.
- Delete evidence before Security confirms disposition.
- Claim that Tier 1 completed malware analysis, forensics, or threat hunting.

## Handoff evidence

Reporter, affected identity/device, timestamp and time zone, sender/location/URL text, interaction status, screenshots or message ID if approved, containment actions, current access state, and user contact status.

## Validate closure

Security records a disposition; required containment and recovery tasks are complete; the user receives clear next steps; and the ticket distinguishes Tier 1 actions from Security's simulated investigation.
